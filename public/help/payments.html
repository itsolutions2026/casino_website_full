What fiat payment gateways are supported?

The following fiat payment gateways are supported:

  • Paypal (deposits)
  • Stripe (deposits)
  • Skrill (deposits)
What crypto payment gateways are supported?

The following crypto payment gateways are supported:

  • coinpayments.net (deposits and withdrawals)
  • cryptapi.io (deposits)
What direct crypto payment methods are available?

The application supports a number of crypto payment methods that allow the client to make direct deposits to the casino address without any intermediaries. The following blockchains and wallets are supported:

  • Any EVM (Ethereum Virtual Machine) chain (Ethereum, Binance Smart Chain, Polygon etc) through Metamask wallet (on desktop) or a web3 compatible wallet (on mobile). All coins and tokens are supported.
  • Tron through Tronlink wallet (TRX and TRC20 tokens).
  • Solana through Phantom wallet (only SOL).

When a deposit is made using one of the above methods, it will be automatically completed in a short period of time after the transaction is confirmed by the blockchain. The user account in the application will be credited automatically.

The casino admin can also process withdrawals using the above methods (wallets). In this case, the admin is expected to complete the payment on the withdrawal page by signing the transaction from their wallet, which can be done with just a few clicks.

How to integrate PayPal?
  • Log in to your PayPal account
  • Move your mouse over the Tools menu in top navigation. Find More Tools within that. And click it.
  • Scroll the page till you see a box with API credentials written. Click on it.
  • Shortcut: click on this link to directly open Tools page in your PayPal account.
  • Once on the API credentials page, click on the last option for NVP/SOAP API integration.
  • If this is the first time you are creating API credentials, complete the API Credential Request form.
  • Once you’ve created the API credentials, you will see View API Signature option under NVP / SOAP API integration. Clicking on that will bring you to a page like the following screenshot. Click on each Show link to see API username, password and signature.
  • Input these keys in Backend » Settings » Add-on: Payments » Paypal.
  • Go to Backend » Deposit methods, find the deposit method linked to the Paypal gateway, click Edit, change its status to Enabled and click Save.
How to integrate Stripe?
  • Sign up at stripe.com and log in to your account.
  • Open Developers » API keys page and create a new set of API keys.
  • Copy Public key and Secret key. Input these keys in Backend » Settings » Add-on: Payments » Stripe.
How to integrate Freekassa?
  • Sign up at freekassa.ru and log in to your account.
  • Add a new merchant (website) and note the Merchant ID.
  • Go to Settings page, generate Merchant API key, Secret word 1 and Secret word 2 and enable Payment verification checkbox.
  • Input your Merchant ID, Merchant API key, Secret word 1 and Secret word 2 in Backend » Settings » Add-on: Payments » Freekassa.
  • Copy Notification URL, Successful payment return URL and Error payment return URL from the app settings page and paste them on the Freekassa settings page.
  • Notification URL method should be set to POST.
  • Go to Backend » Deposit Methods page, find Freekassa method and click Edit. Fill Reference currency and Reference exchange rate. Change the deposit method status to Enabled and click Save.
  • To enable withdrawals go to Backend » Withdrawal Methods page, find Freekassa method and click Edit. Fill Reference currency, Reference exchange rate and choose one of the supported payment methods. Change the withdrawal method status to Enabled and click Save.
How to integrate coinpayments.net?
  • Sign up at coinpayments.net.
  • Open Account » Coin Acceptance Settings page and select coins that you would like to accept (these coins will be available for deposits and withdrawals).
  • Open Account » Account Settings page, select Merchant Settings tab and fill IPN Secret field. It can be any random alphanumeric string. Do not fill IPN URL, leave it blank.
  • Open Account » API keys page and click Generate new key button. After it is generated click Edit Permissions button and enable the following permissions:
    • get_basic_info
    • create_transaction
    • get_tx_info
    • balances
    • create_withdrawal
    • Allow auto_confirm = 1 in create_withdrawal (only in case you like to enable auto confirmation of withdrawals)
    • get_withdrawal_info
    • rates
  • Copy Merchant ID, Public key, Private key and IPN Secret. Input these keys in Backend » Settings » Add-on: Payments » Coinpayments.
  • Open Backend » Deposit Methods page, find Coinpayments method and click Edit. Fill Reference currency and Reference exchange rate fields. Reference currency can be any supported coin or fiat currency, e.g. USD or EUR. Change the deposit method status to Enabled and click Save.
  • Open Backend » Withdrawal Methods page and complete the same steps as in the previous point.
If you use a firewall or some external security service such as Cloudflare make sure to white list all GET / POST requests to all URLs that start with /api/webhooks, otherwise instant payment notification (IPN) messages will not reach your website and hence deposits / withdrawals will stuck in Pending status.
How to integrate cryptapi.io?
  • Open Backend » Settings » Add-on: Payments » CryptAPI and input a secret key. It can be any alphanumeric string (without spaces).
  • Open Backend » Deposit Methods page, choose one of the methods linked to CryptAPI gateway and click Edit.
  • Fill in the Deposit Address, where users will send their coins.
  • Fill in the Reference currency and Reference exchange rate fields. Reference currency can be the coin itself (fixed conversion rate) or one of the supported fiat currencies, e.g. USD or EUR (dynamic conversion rate).
  • In case of an ERC20, BEP20, or TRC20 token fill in the Ticker field. List of supported token tickers (symbols).
  • Optionally fill in or change the fields Number of confirmations, Email and Payment priority.
  • Change the deposit method status to Enabled and click Save.
How to set up payments on Ethereum, BSC, Polygon, smartBCH chains through Metamask?

Deposit and withdrawal methods for Ethereum, BSC, Polygon and smartBCH chains are already predefined. To enable deposits for one of the above chains (in the main coin or token) please do the following:

  • Go to Backend » Deposit Methods.
  • Choose one of the predefined deposit methods (for the chain you are interested in) that is linked to EVM Blockchain payment gateway and click Edit.
  • Set the Deposit Address, where users will send their coins to.
  • If necessary, change the Reference currency and Reference exchange rate.
  • For deposit methods where the Payment method is set to Coin the Reference currency can be set to either the main coin (ETH, BNB, MATIC etc) for a fixed exchange rate, or USD for a dynamic exchange rate. If it is set to USD the payment amount will be calculated automatically based on the internal USD / credits rate and the market rate against USD (pulled from the crypto API defined in Backend » Settings » Services » Crypto API).
  • Irrespective of the Reference currency value the Base coin must always be set to the main coin (ETH, BNB, MATIC etc). Please note that the auto conversion feature is only available for coins, not tokens.
  • Change the deposit method status to Enabled and click Save.

Go to Backend » Withdrawal Methods to set up the corresponding withdrawal methods accordingly. Please note that in order to complete a withdrawal request using this method the admin is expected to make the payment using their Metamask wallet. This can be done on the withdrawal request page.

To make payments using this method users need to install Metamask browser extension. Please note that this extension works only in desktop browsers. To make payments on mobile phones users need to use a DApp browser, e.g. the one provided by Trust Wallet.
How to set up payments on other EVM chains through Metamask?

The below approach allows to set up deposits and withdrawals for any EVM blockchain (in the main coin or token). All you need to know is the RPC node URL. You can use a public node or set up your own. The application communicates with the node to pull address balances and transactions.

To set up a deposit method for an arbitrary EVM chain, follow these steps:

  • Go to Backend » Deposit Methods.
  • Click Create deposit method.
  • Choose EVM Blockchain as the Payment gateway.
  • Choose Coin or Token as the Payment method.
  • Input any alpha numeric identifier as the method Code and enter the method Name.
  • Specify JSON-RPC URL. You can use services like Infura, Alchemy and the like.
  • Set the Deposit Address, where users will send their coins to.
  • Set the Reference currency and Reference exchange rate.
  • For deposit methods where the Payment method is set to Coin the Reference currency can be set to either the main coin (ETH, BNB, MATIC etc) for a fixed exchange rate, or USD for a dynamic exchange rate. If it is set to USD the payment amount will be calculated automatically based on the internal USD / credits rate and the market rate against USD (pulled from the crypto API defined in Backend » Settings » Services » Crypto API).
  • Irrespective of the Reference currency value the Base coin must always be set to the main coin (ETH, BNB, MATIC etc). Please note that the auto conversion feature is only available for coins, not tokens.
  • Change the deposit method status to Enabled and click Save.

Go to Backend » Withdrawal Methods to set up the corresponding withdrawal methods accordingly. Please note that in order to complete a withdrawal request using this method the admin is expected to make the payment using their Metamask wallet. This can be done on the withdrawal request page.

To make payments using this method users need to install Metamask browser extension. Please note that this extension works only in desktop browsers. To make payments on mobile phones users need to use a DApp browser, e.g. the one provided by Trust Wallet.
How to enable auto withdrawals for the EVM chain?

If a withdrawal method is linked to an EVM gateway it's possible to configure automatic withdrawals, which do not require an administrator to complete them manually. For automatic withdrawals to work, you will need to provide the private key of the wallet from which funds are to be sent and the URL of the RPC node. Every five minutes the application will select withdrawals requests that should be processed automatically. It will then send transactions to the blockchain and sign them on behalf of the wallet (address) owner.

To enable automatic withdrawals, follow these steps:

  • Go to Backend » Withdrawal Methods.
  • Find the corresponding withdrawal method and click Edit.
  • Make sure to fill JSON-RPC URL. You can use services like Infura, Alchemy and the like.
  • Activate the switch Auto process.
  • Input the Primary key of the address, where the coins or tokens should be sent from. How to export an account's private key from Metamask?
  • Optionally specify the auto withdrawal Limit.
  • Click Save.
The application stores the private key in the database. Please be careful when providing access to your server or the app backend to other people, because this can lead to the loss of funds in the wallet. It's recommended to set up a separate wallet for automatic withdrawals and replenish it when necessary.

For payments in TRX the Reference currency can be set either to TRX (fixed exchange rate) or USD (dynamic exchange rate). If it is set to USD the payment amount in TRX will be calculated automatically based on the internal USD / credits rate and the market TRX / USD rate (pulled from the crypto API defined in Backend » Settings » Services » Crypto API). To make payments using this method users need to install Tronlink browser extension. Please note that this extension works only in desktop browsers. To make payments on mobile phones users need to use a DApp browser, e.g. the one provided by Tronlink mobile app.

How to set up a manual payment method?
  • Open Backend » Deposit Methods page, click Create deposit method.
  • Fill Code, Name, Description, Reference currency and Reference exchange rate fields.
  • Add any number of extra fields that users will require to fill when submitting a deposit request. For example, you might want users to fill some wallet ID that they will send the funds from.
  • Change the method status to Enabled and click Save.
  • Open Backend » Withdrawal Methods page and complete the same steps.

Manual deposits and withdrawals are not automatically completed and the administrator is expected to complete them manually one by one.

Why deposits are stuck in Pending state?

Make sure that the cron job specified on Backend » Maintenance page is added to your server. Please check the installation guide for more info how to set up a cron job.

I get a 500 server error after completing a deposit

Go to Backend » Settings » Email » Driver and double check that correct SMTP server credentials are specified. If the error persists enable Debug mode (Backend » Settings » Logging) to get more info about the error.
